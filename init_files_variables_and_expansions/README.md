# Shell, init files, variables and expansions

- `0-alias`: creates an alias `ls` that runs `rm *`
- `1-hello_you`: prints `hello` followed by the current user
- `2-path`: adds `/action` to the end of `PATH`
- `3-paths`: counts the directories in `PATH`
- `4-global_variables`: lists environment (global) variables
- `5-local_variables`: lists local and environment variables and functions
- `6-create_local_variable`: creates a local variable `BEST` set to `School`
- `7-create_global_variable`: creates a global variable `BEST` set to `School`
- `8-true_knowledge`: prints 128 plus `TRUEKNOWLEDGE`
- `9-divide_and_rule`: prints `POWER` divided by `DIVIDE`
- `10-love_exponent_breath`: prints `BREATH` to the power `LOVE`
- `11-binary_to_decimal`: converts `BINARY` from base 2 to base 10
- `12-combinations`: prints every two-letter combination from aa to zz except oo
- `13-print_float`: prints `NUM` with two decimal places
- `14-decimal_to_hexadecimal`: converts `DECIMAL` from base 10 to base 16
- `15-rot13`: encodes and decodes text with rot13
- `16-odd`: prints every other line of its input, starting with the first
- `17-water_and_stir`: adds `WATER` (base water) and `STIR` (base stir.) and prints the result in base bestchol
